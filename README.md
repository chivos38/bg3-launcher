\# BG3 Launcher



Лаунчер-помощник для кооперативных каток в Baldur's Gate 3: одним кликом запускает

Teams, Radmin VPN, трейнер и саму игру — в нужном порядке и с правильными паузами.



Тёмный интерфейс, пресеты запуска, автозапуск вместе с Windows и логирование —

чтобы «у меня не работает» всегда сопровождалось файлом с логом, а не пересказом словами.



\## ✨ Возможности



\- \*\*Автопоиск программ\*\* — setup сам находит Teams, Radmin VPN и игру через Steam.

&#x20; Руками выбирать файл не придётся (только трейнер, если не найдётся сам).

\- \*\*Пресеты запуска\*\* — кнопки «Соло» (трейнер + игра), «Кооп» (Radmin + игра),

&#x20; «Всё сразу» (Teams + Radmin + трейнер + игра).

\- \*\*Автозапуск с Windows\*\* — галочка в окне лаунчера, без лазания в реестр.

\- \*\*Лог в файл\*\* — всё, что произошло при запуске, пишется в `\_app/launcher.log`.

\- \*\*Все пути в config.ini\*\* — код трогать не нужно, настройки лежат в текстовом файле.

\- \*\*Тёмный интерфейс\*\* — виндовому окну с тогглами до такого далеко 🙂



\## 🚀 Как запустить (для тех, кто просто хочет играть)



1\. Скачай репозиторий: зелёная кнопка \*\*Code → Download ZIP\*\* (или `git clone`).

2\. Распакуй в любую папку.

3\. Запусти \*\*`setup.bat`\*\* — программа сама найдёт всё нужное.

&#x20;  Чего не нашла — попросит выбрать файл мышкой. По окончании покажет итог: что найдено, что нет.

4\. Запускай \*\*`BG3 Launcher.vbs`\*\* — и играй.



> Порядок важен: сначала `setup.bat` (создаёт `\_app/config.ini`), потом `.vbs`.



\## 🛠 Если что-то пошло не так



\- \*\*Setup не нашёл программу\*\* — он предложит выбрать `.exe` вручную в стандартном

&#x20; окне выбора файла. Ничего прописывать руками не нужно.

\- \*\*Игра не нашлась через Steam\*\* — проверь, что Steam установлен. Лаунчер читает

&#x20; путь из реестра и `libraryfolders.vdf`, так что играет найдётся даже на нестандартном диске.

\- \*\*Лаунчер молча не открывается\*\* — открой `\_app/launcher.log` и `\_app/setup\_report.txt`,

&#x20; там написано, что случилось. Эти же файлы удобно прислать автору 🙂

\- \*\*Путь к программе поменялся\*\* (переустановил, переехал на другой диск) —

&#x20; просто запусти `setup.bat` ещё раз.



\## 📁 Структура



```

BG3 Launcher.vbs      ← единственный видимый файл, его и запускаешь

setup.bat             ← одноразовая настройка (автопоиск программ)

\_app/

&#x20; launcher.ps1        ← сам лаунчер (интерфейс и логика)

&#x20; autodetect.ps1      ← автопоиск программ для setup.bat

&#x20; config.ini          ← создаётся setup'ом, у каждого свой (не в репозитории)

&#x20; launcher.log        ← лог работы (не в репозитории)

```



\## ⚠️ Важно



\- В репозитории \*\*нет ни игры, ни трейнера\*\* — только скрипты.

\- Все пути хранятся локально в `\_app/config.ini` и никуда не отправляются.

\- Трейнер — стороннее ПО, вы используете его на свой страх и риск.

\- Личные файлы (`config.ini`, логи) исключены через `.gitignore`.



\## 🔧 Требования



\- Windows 10/11

\- PowerShell 5.1+ (встроен в Windows)
